# Relationship to Natalia App and Quote Ledger

Natalia’s application is a separate product with a richer devotional/study loop. It is not a feature backlog for this homepage.

Use Natalia work as research heat: interaction ideas, trust failures, calendar lessons, source/provenance lessons. Import a feature only if it serves this homepage’s minimalist doctrine.

`bahai-quote-ledger` is an upstream provenance/corpus project. It may later export curated collections. Do not copy its entire ledger into the public homepage repo, and do not couple homepage runtime directly to private ledger internals without a deliberate export contract.
