# Decision Ledger

**Format: append-only.** Record a new decision by adding a new entry; supersede an old one by adding an entry
that names and replaces it. **Never edit or delete history here** — a cold-start agent must be able to trust
that this file says what was decided *at the time*, not what is convenient now.

Decision dates are recorded in the entry. Sources are named explicitly: the Phase 0 audit document or the
owner-review answer (`bootstrap/packets/2026-09-10-phase1-agent-first-retrofit/OWNER_DECISIONS.md`, Q1–Q5).

---

## D1 — The product is the minimalist single-passage Hidden Words homepage · accepted 2026-09-10

Product = one Hidden Words passage per Gregorian day-of-year over the ≤75-word subset, Badíʿ date, light
"Yesterday" recall, clipboard copy, persistent theme. The doctrine reconstructed in
`docs/audit/2026-09-10/PRODUCT_DOCTRINE_RECONSTRUCTION.md` is canonical.

*Why:* it is what the running code actually does, and the reconstruction tested each seed claim against
observed behavior rather than assuming intent.

*Source:* `PRODUCT_DOCTRINE_RECONSTRUCTION.md` (Phase 0 audit).

## D3 — Wallpaper + iOS widget are experimental ambient surfaces · accepted 2026-09-10

`wallpaper.html` / `js/wallpaper.js` / `css/wallpaper.css` and `ios/widget/*` stay in place, documented and
doc-linked from `README.md` / `AGENTS.md` as experimental, and **outside the parity path**.

*Why:* both are live-but-unlinked and harmless once a cold-start agent can tell they are experimental;
deleting them would destroy in-flight intent, building them out would be unjustified churn. The widget has
no `.xcodeproj` and is not buildable in-repo — docs must say so.

*Source:* `OWNER_DECISIONS.md` Q1.

## D4 — Orphaned multi-faith payload: unpublished from `main`, retained on `archive/legacy-multifaith` · accepted 2026-09-10

Removed from the published `main` tree (7 paths): `data/quotes_kjv_bible.json`,
`data/quotes_dhammapada.json`, `data/quotes_gita_arnold.json`, `data/quotes.json`,
`scripts/scrape_kjv_bible_pg.py`, `scripts/scrape_dhammapada_pg.py`, `scripts/scrape_gita_arnold_pg.py`.
The bytes are retained on a pushed, never-merged `archive/legacy-multifaith` branch.

*Why:* GitHub Pages here is `build_type: legacy`, source `main` / `/`, and `.nojekyll` disables Jekyll's ignore
rules — the **whole branch is served publicly**, so moving the files into a repo subdirectory would not
unpublish them. Only removal from `main` stops serving; the archive branch keeps restoration to one command,
so the ~10 MB dead-provenance payload leaves the public surface with nothing destroyed.

*Source:* `OWNER_DECISIONS.md` Q2 (includes the mechanism correction).

**Restoration command (one line, from `main`):**

```bash
git checkout archive/legacy-multifaith -- \
  data/quotes_kjv_bible.json data/quotes_dhammapada.json data/quotes_gita_arnold.json data/quotes.json \
  scripts/scrape_kjv_bible_pg.py scripts/scrape_dhammapada_pg.py scripts/scrape_gita_arnold_pg.py
```

**Kept deliberately:** `data/quotes_hidden_words.json`, `scripts/scrape_hidden_words.py`,
`scripts/validate_quotes.py`, `ios/widget/quotes_hidden_words.json`.

*Source:* `OWNER_DECISIONS.md` Q5. Executor note appended by H1.

## D9 — README Appendix A retired; the agent contract now exists as root `AGENTS.md` · accepted 2026-09-10

The agent contract lives at root `AGENTS.md`, byte-identical to the text that had been preserved verbatim in
`README.md` Appendix A. The appendix is removed and every reference to it (`README.md` ×3, `docs/RUNBOOK.md`)

*Why:* D7's appendix was a documented fallback, not the preferred delivery, and its manual step has now been

time either copy was edited.

*Source:* `OWNER_DECISIONS.md` Q5 and D7. This entry closes D7's fallback clause additively; D7's own text is
not edited (append-only ledger).
